# 宇树 G1 语音对话优化前后对比

测试时间：2026-09-01  
测试方法：优化前后使用同一组 10 个问题，连续执行知识库检索、模型生成、TTS 合成、音频转换和机器人播放；每组均为首次顺序执行，不使用回答缓存。

## 本轮优化内容

1. 将语音场景模型从 `qwen-plus` 调整为低延迟的 `qwen-turbo`。
2. 回答约束由最多 80 字改为一句话、40 字以内，减少生成和播报等待。
3. 对话历史由 5 轮缩减为 3 轮，知识库候选由 3 条缩减为 2 条，减少输入上下文。
4. TTS 语速由 `+5%` 调整为 `+15%`，在保持清晰的前提下缩短播放时间。

## 指标边界

当前 ASR 服务只输出最终识别文本，没有语音结束事件；本次没有取得可靠的“用户说完到 ASR 最终结果”数据，因此不填造 ASR 耗时。表中的系统首响从收到 ASR 最终文本开始计算。后续端到端口到耳首响应等于 ASR 耗时加系统首响。

## 下一阶段建议

当前最大剩余瓶颈是 TTS 合成（平均 1814 ms）。下一阶段可改为流式 TTS：模型生成首句后立即合成并将首批 PCM 推送至机器人，目标是把系统首响进一步压到 1.5 秒左右。该改动涉及播放链路，需要另做音质、断句和长时间稳定性验证。
